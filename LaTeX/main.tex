    : g ^ n = 1) :
    Multiplicative (ZMod n) →* G :=
  MonoidHom.mk' (fun a => g ^ (Multiplicative.toAdd a).val) fun a b =>
      by
    have hpow : ∀ k : ℕ, g ^ k = g ^ (k % n) := by
      intro k
      conv_lhs => rw [← Nat.div_add_mod k n]

\section{Final summary: current mathlib number field API}

The current API is already strong for low-degree explicit fields.  It supports:
cyclotomic fields and primitive roots, \verb|AdjoinRoot| models, integral closures and
integral power bases, algebra norms and discriminants, ideals with absolute norm,
ramification/inertia, class groups, Minkowski-bound class number proofs, and Galois
groups.

The most successful patterns in this folder are:
\begin{itemize}
\item Cyclotomic ring-of-integers proofs: \verb|IsCyclotomicExtension| gives very direct integral bases.
\item Quadratic and small cubic norm-form computations: once the basis is explicit, many ideal and unit facts reduce to arithmetic.
\item Class group proofs: \verb|exists_ideal_in_class_of_norm_le| plus explicit small-prime splitting is powerful enough for class number \(1\) and \(2\) examples.
\item Galois groups: cyclotomic Galois groups and quadratic conjugation are well supported.
\end{itemize}

The main rough edges are:
\begin{itemize}
\item Concrete Dirichlet units: mathlib has abstract \verb|fundSystem| APIs, but proving a displayed unit is the chosen generator still needs bespoke Pell/cyclotomic-unit work.
\item Regulators: comparing concrete logarithmic embeddings with mathlib's regulator API, especially \verb|Units.regulator|, is not yet ergonomic.
\item Norm-Euclidean proofs in degree \(3\) and \(4\): the missing part is mostly reusable geometry-of-numbers or lattice-rounding infrastructure.
\item Prime splitting proofs are repetitive: many files rebuild residue maps and kernel computations that should be abstracted into a reusable ``factor minimal polynomial mod \(p\) gives ideal factorization'' API.
\end{itemize}

Promising optimization routes:
\begin{itemize}
\item Build a reusable residue-hom/kernel lemma for \(\mathbb Z[\alpha]/(p,f_i(\alpha))\).
\item Add automation for norm forms from a \verb|PowerBasis| or \verb|Basis|.
\item Package Minkowski-bound class-number-one proofs into a theorem requiring only the finite list of small principal prime ideals.
\item Strengthen concrete unit APIs: Pell variants for nonmaximal-looking coordinates, cyclotomic units, and regulator evaluations.
\item Create Euclidean templates for quadratic, pure cubic, and quartic cyclotomic lattices.
\end{itemize}
