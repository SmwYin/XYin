## Proof and scope

The theorem checks finiteness on the **target** quotient chart cover using
`IsZariskiLocalAtTarget.iff_of_openCover`. Each required morphism is the actual
`pullback.snd` of the global projection along a target chart inclusion.
The previously checked literal chart square, flipped, supplies its comparison
isomorphism. `IsPullback.isoPullback_inv_snd` rewrites this restriction as that
isomorphism's inverse followed by the actual finite local quotient projection.
Finiteness is preserved by this composition. The orientation is correct.

The proof installs the actual `free_gluePatch` instance and invokes the checked
invariant-ring finite local projection. It does not try to descend finiteness
through an arbitrary source cover, and it does not require target chart
inclusions themselves to be finite. The latter would be an invalid shortcut.

The public wrapper uses the precise chosen integer `G.killN` and proof
`G.killN_spec`. The arbitrary `Spec R` constant-axis wrapper installs the
directly proved `HasKillingInt`, and the level-3 example uses an actual full
complex point and its native pullback curve. No field, domain, Noetherian,
étale, or faithful-action hypothesis enters the finite theorem.
